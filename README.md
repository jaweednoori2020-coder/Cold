# حساب سرد خانه عبدالعزیز

وب‌اپلیکیشن فارسی/دری برای مدیریت سردخانه دو طبقه، مشتریان، کرایه، مصارف، پرداخت‌ها و سهم شرکا.

## اجرای GitHub Pages
1. تمام فایل‌های این پوشه را در ریشه Repository قرار دهید.
2. GitHub Pages را روی branch موردنظر فعال کنید.
3. برنامه بدون Backend اجرا می‌شود و داده‌ها را در مرورگر دستگاه نگه می‌دارد.

## فایل عکس
فایل `profile.jpg` در ریشه پروژه قرار دارد و داخل `assets` نیست. برای تغییر عکس، همین فایل را جایگزین کنید.

## نکته Backup
اطلاعات در همان مرورگر ذخیره می‌شود. قبل از پاک‌کردن داده‌ها یا تغییر دستگاه، از بخش تنظیمات Backup JSON بگیرید.
